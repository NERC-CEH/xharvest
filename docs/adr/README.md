# Architecture decision records

Each file records one decision, numbered in the order the decisions were made.

- An accepted record's decision is not edited: a later decision that changes it gets a record of its own, which says what it supersedes.
- Details that have gone stale, such as file paths, are corrected in place wherever they could mislead.
- A new record takes the next number and follows the format of the existing ones: status, date, context, decision, consequences.
